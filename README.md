# GCG TABLE

ガンダムカードゲームの非公式ローカル対戦アプリです。知人とカードを並べる感覚で遊ぶための手動シミュレーターで、Windows PC同士をRadmin VPNまたはHamachiで接続して使います。

## ダウンロードして遊ぶ

**[最新版のダウンロードページ](https://github.com/karadaga1236/gcg-table/releases/latest)** を開き、Assetsから **GCG-TABLE-v4.6-Windows-x64.zip** をダウンロードしてください。

「Code → Download ZIP」や「Source code」は開発用のソースです。遊ぶ場合は上記のWindows用ZIPを選んでください。実行環境と収録カード画像を同梱しているので、Node.jsやGitのインストールは不要です。

1. ZIPを右クリックして **「すべて展開」** します。ZIP内から直接起動しないでください。
2. 展開したフォルダーの **「起動.cmd」** を開きます。ブラウザーでアプリが開きます。黒い起動画面は開いたままにします。
3. 知人と同じRadmin VPN／Hamachiネットワークへ接続します。
4. ホストは **「部屋を作る」→「部屋を作成する」**。
5. 相手は自分のPCで同じ「起動.cmd」を開き、**「部屋に入る」**で見つかった部屋をクリックします。自動検出で見つからない場合は、招待情報を共有して参加できます。
6. 両方がデッキを登録してダイスを振り、勝った人が先攻・後攻を選んでから、ホストが「初手を配る」を押します。

ホスト・参加者で起動ファイルを分ける必要はありません。招待情報には接続先と部屋番号がまとまっています。課金・クラウド契約は不要です。

一人で試す場合は「一人で動作確認する（VPN不要）」で部屋を作り、新しいタブで同じアプリを開いて招待情報を入力してください。

## 主な機能

- カード画像を使った対面形式の盤面、レスト時の90度回転。
- 左詰めの6列表示、左側でユニットとパイロットを並べて確認。相手の手札は裏面カードと大きな枚数表示。
- カードをドラッグして移動・セット。クリックで選択した後、空きエリアをクリックしても移動しません。
- 自分の山札をクリックして1枚ドロー。EXリソースを枚数・向き指定で追加。
- 配備ターンの召喚酔い表示。名前の含有一致、複数候補・特徴による通常リンクを判定し、効果による変更は手動で表示変更。
- 通常のターン開始時にアクティブ化・ドロー・リソース追加を自動処理。各フェイズで止める設定もあります。
- ダイスの勝者が先攻・後攻を選択。プレイヤー名は同じブラウザーで前回の入力を保持。
- 部屋作成時にBO1（1ゲーム）・BO3（2勝先取）を選択。BO3のゲーム間にサイドボードを入れ替え。
- サイドボードも各プレイヤーのデッキと一緒にローカル保存。
- コマンド使用中の画像を両者に公開し、「処理完了」でトラッシュへ。
- カード検索、色・種類・Lv.・COST・弾の絞り込み。特徴は複数選択のOR検索。
- 右側をカード検索／編集中のデッキ／マイデッキに切り替え、大きな画像で一覧表示。
- 同じVPN内の部屋を自動検出してクリック参加。直接攻撃の勝利を双方で確認して確定するボタン。
- プレイヤー別の複数デッキを、自分のアプリ内のdata/decksフォルダーへ保存。
- リソースのまとめ払い、デッキ上部の非公開確認・選択公開・戻し順指定、複数カードの一括移動。
- セットしたカードの印刷AP・HPをユニット上の数値に自動加算。一時的な補正・効果メモにも対応。
- 対戦終了後に両者が同じデッキ／選び直しを選んで、同じ部屋で再戦。
- 画像・能力値付きユニットトークン35種の選択配備、Lv.・印刷能力タグ、一括AP・HP補正。
- 公開されたカードを両者の盤面右側へ自動表示。
- EXベースの専用除外ボタン。カード固有の条件・対象・戦闘の判断は手動。

## 更新するとき

旧版の黒い起動画面でCtrl＋Cを押して終了し、新版を別フォルダーへ展開してください。旧版でデッキを保存していた場合は、**旧版のdataフォルダーを控えとしてコピーしたうえで、新版へ引き継ぎます。** 保存済みのdataを空のフォルダーで上書きしないでください。

## 対応環境・確認状況

- Windows 64ビット。Node.js v24.19.0を同梱しています。
- カード情報・画像は2026年10月14日時点の通常版956種＋リソース等3種（2026年10月17日にユニットトークン35種を追加）。自動更新はありません。
- 自動テスト70件と同じPC上の2アプリ間の参加を確認済みです。**別PC同士のVPN対戦は未検証の試作版**です。
- アプリ終了で対戦進行は消えます。保存済みデッキは残ります。
- ホストのPCで対戦状態を管理します。カード効果・構築条件・勝敗全般の完全自動判定ではありません。

詳しい操作は[はじめに](はじめに.md)と[共通操作ガイド](共通操作ガイド.md)、確認範囲は[検証結果](検証結果.md)をご覧ください。不具合はIssuesに、操作手順とエラー文を添えて報告できます。招待情報や個人の保存データは投稿しないでください。
