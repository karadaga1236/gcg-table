# GCG TABLE

ガンダムカードゲームの非公式ローカル対戦アプリです。知人とカードを並べる感覚で遊ぶための手動シミュレーターで、Windows PC同士をRadmin VPNまたはHamachiで接続して使います。

## ダウンロードして遊ぶ

**[最新版のダウンロードページ](https://github.com/karadaga1236/gcg-table/releases/latest)** を開き、Assetsから **GCG-TABLE-v4.1-Windows-x64.zip** をダウンロードしてください。

「Code → Download ZIP」や「Source code」は開発用のソースです。遊ぶ場合は上記のWindows用ZIPを選んでください。実行環境と収録カード画像を同梱しているので、Node.jsやGitのインストールは不要です。

1. ZIPを右クリックして **「すべて展開」** します。ZIP内から直接起動しないでください。
2. 展開したフォルダーの **「起動.cmd」** を開きます。ブラウザーでアプリが開きます。黒い起動画面は開いたままにします。
3. 知人と同じRadmin VPN／Hamachiネットワークへ接続します。
4. ホストは **「部屋を作る」→「部屋を作成する」→「招待をコピー」**。招待情報を知人に送ります。
5. 相手は自分のPCで同じ「起動.cmd」を開き、**「部屋に入る」** に招待情報を貼り付けます。
6. 両方がデッキを登録してダイスを振り、ホストが「初手を配る」を押します。

ホスト・参加者で起動ファイルを分ける必要はありません。招待情報には接続先と部屋番号がまとまっています。課金・クラウド契約は不要です。

一人で試す場合は「一人で動作確認する（VPN不要）」で部屋を作り、新しいタブで同じアプリを開いて招待情報を入力してください。

## 主な機能

- カード画像を使った対面形式の盤面、レスト時の90度回転。
- 通常のターン開始時にアクティブ化・ドロー・リソース追加を自動処理。各フェイズで止める設定もあります。
- ダイスによる先攻・後攻の決定。
- カード検索、色・種類・Lv.・COST・弾・特徴（「学園」など）による絞り込み。
- プレイヤー別の複数デッキを、自分のアプリ内のdata/decksフォルダーへ保存。
- カード移動・効果処理・リソース支払い・戦闘処理は手動。

## 更新するとき

旧版の黒い起動画面でCtrl＋Cを押して終了し、新版を別フォルダーへ展開してください。旧版でデッキを保存していた場合は、**旧版のdataフォルダーを控えとしてコピーしたうえで、新版へ引き継ぎます。** 保存済みのdataを空のフォルダーで上書きしないでください。

## 対応環境・確認状況

- Windows 64ビット。Node.js v24.19.0を同梱しています。
- カード情報・画像は2026年10月14日時点の通常版956種＋リソース等3種。自動更新はありません。
- 自動テスト30件と同じPC上の2アプリ間の参加を確認済みです。**別PC同士のVPN対戦は未検証の試作版**です。
- アプリ終了で対戦進行は消えます。保存済みデッキは残ります。
- ホストのPCで対戦状態を管理します。カード効果・構築条件・勝敗全般の完全自動判定ではありません。

詳しい操作は[はじめに](はじめに.md)、確認範囲は[検証結果](検証結果.md)をご覧ください。不具合はIssuesに、操作手順とエラー文を添えて報告できます。招待情報や個人の保存データは投稿しないでください。
